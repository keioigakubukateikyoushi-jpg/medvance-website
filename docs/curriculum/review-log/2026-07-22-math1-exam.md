## 致命的問題（Must fix）

### M1. ME-M1-21 が ME-M1-39 を prereq に持たない（飛び）

- **問題**: 漏れリストは「1次不等式は絶対値不等式・**2次不等式**の前提」と明記しているのに、DAG上の `ME-M1-21` prereq は `20` のみ。推奨学習順も `15 → 42 → 20 → 21 → 22` で **39 を経由しない**。2次関数枝（14以降）は prereq=04 起点なので、数と式を途中までしかやっていない学習者が **39未習のまま2次不等式に入れる**。
- **修正案**:
  1. `ME-M1-21` の prereq を **`20, 39`** に変更。
  2. 推奨学習順に明記: `39 完了後に 21 へ`（`11` 経由では保証されない）。
  3. 実装チェックリストに「21 prereq に 39」を追加。
  4. Batch6 の依存に Batch3（39）を明示。

### M2. ME-M1-41（三次展開）は add せず 05 の rewrite に吸収

- **問題**: add 8本のうち **41 は過剰**。受験重要度 B、内容は公式2本＋逆の入口程度で、単独18分・本文≥3000字を要求すると水増し単元になる。現行05は既に「(a±b)³ と (x+a)(x+b)」同居であり、**原子スキルが2つあるのは事実だが、split して新IDを切るほどではない**。06 が a³±b³ を rewrite で抱えるなら、展開側は05内のセクションで足りる。43（特殊角・A級・到達チェック独立）とは質が違う。
- **修正案**:
  1. **ME-M1-41 を add リストから削除**（ID 41 は欠番 or 将来用に予約しない）。
  2. `ME-M1-05` は **split ではなく rewrite**。タイトル例: 「展開：(x+a)(x+b) と (a±b)³」。
  3. 05 内を2ブロック化し、到達チェックを分ける（ブロックA: たして○かけて□／ブロックB: 三次展開1回と符号）。
  4. `ME-M1-06` prereq を **`05` のみ**に戻す。
  5. 章「数と式」設計後単元数 **16 → 15**、科目合計 **46 → 45**、add **8 → 7** に更新。
  6. Batch2 から 41 を外し `06, 07, 08` のみ。Batch1 の05は **狭義スコープにせず三次まで書いてよい**（§7.2・§10-3 の「05を狭めて41は後」条項を削除）。

### M3. ME-M1-23 のスコープ契約が ADV-M1-10 と衝突する

- **問題**:
  - 現行 `ME-M1-23` shell の goal は既に「f-g の符号と共通点の個数」。タイトルだけ「共通接線の入口」。
  - 例題Bは **接する a**（重解・D=0）であり、接線の方程式を求める本論ではない。
  - 発展 `ADV-M1-10` のタイトル／goal は **「2曲線の共有点と上下関係」** で、rewrite 後の23と**ほぼ同名同スキル**。prereq は `ME-M1-23`。
  - Blueprint §1 は「共通接線の本格議論 → ADV-M1-10 / ELI-M-06」と書くが、**ADV-M1-10 は共通接線ユニットではなく、ELI-M-06 が共通接線**。接続ラベルが不正確。
  - 「タイトルから共通接線を削除」だけでは、**基礎を空にしてADVと同内容になる**か、**接する条件まで消してADVの前提が欠ける**かの二択事故が起きる。
- **修正案**（Blueprint にスコープ境界を1表で固定）:

| 層 | ID | 含める | 含めない |
|---|---|---|---|
| 基礎 | ME-M1-23 | f−g=0 の個数、f>g の符号、**接する＝重解（D=0）を例題1本** | 共通接線の方程式、傾き指定、2次関数族、本数議論 |
| 発展 | ADV-M1-10 | パラメータ付き共有・上下、条件の論理整理、**ELIへの橋** | 家族パラメータの共通接線フル（→ELI-M-06） |
| 難関 | ELI-M-06 | 2次関数族と共通接線 | — |

  1. タイトル確定案: **「2曲線の共有点・上下関係と接する条件」**（「共通接線」文言は使わない）。
  2. §1「上層へ送る」を修正: 共通接線の本格 → **ELI-M-06**（経由 ADV-M1-10）。ADV-M1-10 は共有・上下の深化。
  3. 接続表 §6 の「23 → ADV-M1-10」に差分一文を書く（数値係数の基本 vs 文字・論理）。
  4. rewrite 時、現行例題B型（接する a）は **残す**。落とすのはタイトルの「共通接線」と、接線方程式を立てる展開のみ。

### M4. 到達像 D の「解の配置」が単元に落ちていない

- **問題**: 到達像 D 答案列に「**解の配置**を混同しない」とあるが、DAG・問題型カタログ・§8 到達チェックのいずれにも **解の配置の原子スキルがない**。20 は「Dと個数」、21–22 は不等式。医学部で差がつく「両解が区間内」「異なる符号」等は **基礎で1型も固定しない**のに到達像だけが約束している。
- **修正案**（どちらかを Blueprint で選び、曖昧禁止）:
  - **案A（推奨・基礎に閉じる）**: `ME-M1-20` の原子スキルを「判別式・実数解の個数・**解の配置の基本3型**（正の解2つ／異号／指定区間に1つ）」に拡張。分は18→20可。ADV-M1-07 へは複合条件のみ送る。
  - **案B**: 到達像 D から「解の配置」を削除し、「解の配置は `ADV-M1-07` / 存在条件系へ」と §1 上層送りリストに明記。カタログにも同文。

## 改善提案（Should）

### S1. ME-M1-43（特殊角）は add 維持 — 41 と同類視しない

- **判断**: **rewrite 吸収に落とさない**。
- **根拠**: 受験重要度 A、24–26 に埋没すると到達チェック不能（設計者のP1認識は正しい）。26 は 0°–180° の符号・定義拡張で既に重い。値の表を独立ユニットにするのは原子スキルとして妥当。16分はドリル単元として成立し、3000字は「表の導出＋鈍角への拡張手順＋誤記落とし穴」で水増ししにくい。
- **軽い改善**: prereq を `25` のままか、`24` に落とすかを明記。推奨は **`25` 維持**（相互関係後に表を固定）でよい。ただし 43 の範囲を「鋭角表＋90°」に限り、120°以降は 26 で符号付き再掲、でも可。**どちらかを1行で固定**すること。

### S2. 1次不等式（39）の挿入位置は「09の直後」で可。ただし役割を二系統に分けて書け

- **判断**: 位置 `09 → 39` は承認。整式幹（01–08）の後ろに無理に挟まない判断も妥当（1次不等式は多項式操作に依存しない）。
- **不足**: 39 の「客」が **11（絶対値不等式）だけ**に見え、21 への線が無い（→M1）。また並走枝 `09 → 40 → 10` と `09 → 39` の合流が 11 のみで、学習UI上「39をいつやるか」が弱い。
- **修正案**:
  1. 数と式DAG図に **必須合流**: `39 → 11` および **`39 → 21`（章またぎ）** を破線でもよいので書く。
  2. 39 の原子スキル文面に含める: 不等式の性質（辺々に負数）、解の表記（区間）、数直線。**これが21の前提**である旨を goal に1文。
  3. 順序の推奨を固定: `09 → (39 ∥ 40) → 10 → 11` および平方根枝と独立。**39 を 40 より先でも後でも可**と明記し、実装者の迷いを消す。

- Should: 45 の到達チェックを「定義どおり cov を1回計算」に限定し、r の解釈は34に残す（境界を書く）。

### S4. ME-M1-46（データ受験接続）は維持。中身の禁止事項を先に契約

- Should: 36–38 と同様、「31–35 の再講禁止。共通テスト型の読み取り判定フローのみ」を原子スキル欄に先書き（現行36–38の rewrite 方針と揃える）。
