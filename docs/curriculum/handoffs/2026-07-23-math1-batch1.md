## 単元仕様

### ME-M1-02 多項式の加減と同類項

| 項目 | 仕様 |
|---|---|
| goal | 同類項をまとめて多項式の加減をミスなく実行できる |
| prereq | ME-M1-01 |
| 次 | ME-M1-03 |
| minutes | 16 |
| 原子スキル | 同類項の定義 → かっこ外し（符号） → 係数加減 → 降べき |
| **含めない** | 展開（03以降）、因数分解、2変数の本格（xy は同類項判別の例まで可） |

**必須で扱う型**

1. 1変数の加減: `(3x²−2x+5)+(−x²+4x−1)−(2x²−x−3)` 級  
2. 引き算のかっこ全体への負号  
3. 2変数の入口: `2A−3B`（A,B が x²,xy,y²）で xy と yx が同類  
4. 降べき・次数の再確認（01接続）

**落とし穴（最低3・推奨5）**

- 引き算のかっこ符号反転漏れ  
- x² と x を同類と誤認  
- xy と yx を別物扱い  
- 係数の符号落とし  
- 定数項の紛失  

**クイズで測ること**

- 同類項の定義（指数込み）  
- 符号反転1問  
- 具体計算1–2問  
- 「なぜ xy と yx は同類か」短答  

**現行の問題**: 本文~900字、演習1、クイズが写経型。**全置換**してよい。

### ME-M1-03 展開の基本：分配法則と整理

| 項目 | 仕様 |
|---|---|
| goal | (a+b)(c+d) 型を分配法則で展開し降べきで整理できる |
| prereq | ME-M1-02 |
| 次 | ME-M1-04 |
| minutes | 18 |
| 原子スキル | 分配の漏れなく列挙 → 同類項整理 → 降べき |
| **含めない** | 乗法公式 (a±b)² 等（04）、たして○かけて□（05） |

**必須で扱う型**

1. 2×2: `(2x−3)(x+5)`  
2. 2×3 または 3×2: 漏れが出やすい形  
3. 整理後に最高次が残る例  
4. （任意）簡単な文字係数  

**落とし穴**

- 中間項の取りこぼし（「外側だけ」）  
- 符号ミス（負×負）  
- 同類項まとめ前に降べきしようとする  
- 途中式を消して検算不能  

**クイズ**: 展開計算・「何本の積が必要か」・符号・整理後の次数

### ME-M1-04 展開公式 (a±b)² と (a+b)(a−b)

| 項目 | 仕様 |
|---|---|
| goal | 3公式を見極めて適用し、係数・符号ミスを防げる |
| prereq | ME-M1-03 |
| 次 | ME-M1-05 |
| minutes | 18 |
| 原子スキル | 公式選択 → 代入 → 整理。公式を分配で一度証明/導出してから使う |
| **含めない** | (a±b)³、たして○かけて□ の本論（05） |

**必須で扱う型**

1. `(x+3)²` / `(2x−1)²`（係数あり）  
2. `(x+2)(x−2)` および `(3x+1)(3x−1)`  
3. 公式適用か分配かの判断（見た目が公式に見えるがズレている罠を1つ）  
4. 公式の逆方向の入口は **一言** でよい（因数分解は06）

**落とし穴**

- `(a+b)²=a²+b²` 落とし  
- 2ab の係数・符号ミス  
- `(a−b)²` で真ん中を − にしない／2回マイナス  
- 公式に無理当て（分配すべき場面）

### ME-M1-05 展開：(x+a)(x+b) と (a±b)³

| 項目 | 仕様 |
|---|---|
| goal | たして○かけて□ の展開と、三次公式を符号込みで使える |
| prereq | ME-M1-04 |
| 次 | ME-M1-06 |
| minutes | **20**（Blueprint: 2ブロック同居） |
| 原子スキル | **ブロックA** (x+a)(x+b) / **ブロックB** (a±b)³  
| **含めない** | 因数分解本論（06）、たすきがけ（07） |

**Blueprint 確定事項（厳守）**

- **ME-M1-41 は作らない**。三次は05内のブロックB  
- 到達チェックをブロックごとに分ける（AができないのにBだけ、を防ぐ）

**必須で扱う型**

- A: `(x+2)(x+5)`、`(x−3)(x+4)`、係数付き `(2x+1)(x+3)` の整理  
- B: `(x+1)³`、`(x−2)³`、`(2x+1)³` のどれか＋公式の展開形  
- A→B の接続: 「二次の整理が三次の土台」

**落とし穴**

- たして○かけて□ の符号（和と積の混同）  
- `(a+b)³=a³+b³` 落とし  
- 3a²b / 3ab² の入れ替え  
- ブロックBだけで満足してAの検算を飛ばす  

**クイズ**: Aから2問・Bから2問・横断1問（どの公式を使うか）
