なぜこの層か

攻略の方針

発展は基礎の手順を速く正確に使い、複合条件を分解する力が中心。

前提チェック

この回のポイント

  • 絶対値が2つ以上
  • 中身が1次

定義・用語

複合絶対値の方程式

複合絶対値の方程式を扱うための中心概念。受験では定義を答案の一文目に置けることが得点の土台になる。

核となる手順（答案でこの順）

  1. 零点で数直線を区切る
  2. 各区間で符号を外す
  3. 方程式を解く
  4. 区間に属する解だけ残す

例題A（標準・型の確認）

|x-1|+|x+2|=5 を解け。

解答A

  • 境界 x=-2,1。
  • x<-2: -(x-1)-(x+2)=5 → -2x-1=5 → x=-3（適）。
  • -2≦x<1: -(x-1)+(x+2)=5 → 3=5 不適。
  • x≧1: (x-1)+(x+2)=5 → 2x+1=5 → x=2（適）。
  • 答え x=-3,2。

例題B（受験・実戦）

|x|+|x-2|=2x を解け。

解答B

  • 境界0,2。
  • x<0: -x-(x-2)=2x → -2x+2=2x → x=1/2 不属。
  • 0≦x<2: x-(x-2)=2x → 2=2x → x=1 適。
  • x≧2: x+(x-2)=2x → 2x-2=2x 不適（恒偽）。
  • 答え x=1。

演習（自力再現）

場合分けの境界はどう決める？

解答

  • 要点: 各絶対値の中身=0 となるx
  • 条件を確認し、同じ手順で再現できるか検算する。

落とし穴（減点パターン）

  • 解を区間に戻さない
  • 境界点の重複処理
  • 符号の外し間違い

到達チェック（完璧の条件）

  • ゴールを何も見ずに言える
  • 例題A・Bを白紙で手順から再現できる
  • 落とし穴を「なぜダメか」まで説明できる
  • 確認クイズで合格点（4/5以上）
