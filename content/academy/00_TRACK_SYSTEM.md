# Medvance — 3層トラック体系

## 約束（完璧マスター）

**基礎講座を教科ハブの順に進め、各単元の到達チェックをすべて満たせば、医学部受験に必要な高校範囲を抜けなくマスターできる。**

詳細マップ: `COVERAGE.md`

---

## 設計原則

1. **飛び飛び禁止**: 各ユニットは原子スキル1つ。前提ユニットIDを必ず持つ  
2. **下層の穴を埋めずに上層に上がらない**  
3. **同一台本12ブロック**（基礎は SHARED_STORYBOARD、発展・難関は ADVANCED/ELITE 版）  
4. **創作しない**: 特定年の入試問題を捏造しない。型・公開可能な一般形・方針で書く  
5. **到達チェック**: ゴール再現・例題白紙・落とし穴説明・クイズ合格  
6. **無料以外**: Medvance塾生見放題・質問し放題

---

## 3層の定義

| 層 | ID | 目的 | 尺 | 問題の質 | 入口 |
|---|---|---|---|---|---|
| **基礎講座** | `foundation` | 高校課程を受験精度で完全カバー | 15–25分 | 標準＋受験基本 | 学年・単元順 |
| **発展講座** | `advanced` | 基礎の上に載る典型応用・融合 | 20–30分 | 難しめ標準〜中堅二次 | 基礎ユニット完了後 |
| **難関大講座** | `elite` | 医学部・最難関の問題型を精読 | 25–40分 | 難関二次・医の型 | 対応する発展完了後 |

```
基礎 (foundation-*)
  └→ 発展 (advanced-*)  ※ prereq に foundation ID
        └→ 難関大 (elite-*)  ※ prereq に advanced ID
```

## フォルダ

```
curriculum/
  00_TRACK_SYSTEM.md          … 本ファイル
  SHARED_STORYBOARD.md        … 基礎12ブロック
  ADVANCED_STORYBOARD.md      … 発展12ブロック（問題中心）
  ELITE_STORYBOARD.md         … 難関12ブロック（精読中心）
  foundation/                 … 既存科目へのポインタ（catalog）
  advanced/
    math1/ math2/ mathA/ english/
  elite/
    math/ english/
  research/                   … NLM deep research ログ・ソース要約
```

既存の `math1-exam` 等は **基礎講座の実体** として維持（移動せずポインタ）。

---

## カバレッジ規則（完全カバーの意味）

### 基礎
- 教科書の全単元を原子スキルに分割済みであること  
- 各ユニットに「次」があり、章内に欠番がないこと  

### 発展
- **基礎の各章について、最低1本以上の発展ユニット**があること  
- さらに章内の「落としやすい応用型」を列挙し、型ごとに1ユニット  

### 難関大
- 分野（数と式／2次関数／三角／指数対数／微積／場合の数／確率…）ごとに  
  **問題型カタログ**を埋め、型ごとに1ユニット  
- 「この型の前にやる発展ID」が空でないこと

## 進捗の見方

`curriculum/catalog.json` の `tracks` 配列:

```json
{ "id": "foundation|advanced|elite", "subjects": [ ... ] }
```

プレビューはトラック → 科目 → ユニットの順で辿る。
