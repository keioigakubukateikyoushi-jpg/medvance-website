# スライド ME-M1-02

## 多項式の加減と同類項
**ゴール** 同類項をまとめて多項式の加減をミスなく実行できる

## ポイント
- 同類項＝文字部分（変数と指数）が一致
- 引き算はかっこ内の**すべての**符号を反転
- $xy$ と $yx$ は同類。$x^2$ と $x$ は別
- 係数だけ加減 → 降べき → 代入検算

## 手順
1. かっこを外す（マイナスなら中を全部反転）
2. 文字部分でグループ化
3. 係数を符号込みで加減
4. 0になった項を消す
5. 降べきで書く
6. 代入で検算

## 例題A
$$(3x^2-2x+5)+(-x^2+4x-1)-(2x^2-x-3)=3x+7$$

## 例題B
$A=2x^2-xy+3y^2$, $B=x^2+4xy-y^2$
$$2A-3B=x^2-14xy+9y^2$$

## 落とし穴
- 引き算で先頭だけ符号変更
- $x^2$ と $x$ を同類扱い
- $xy$ と $yx$ を別物扱い
- 定数項の紛失
